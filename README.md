### 3. Установка и запуск

#### Вариант А: Запуск в один клик (рекомендуется, если не переживаете за windows security)
Просто запустите файл `run_project.bat` в корне проекта. Он автоматически установит зависимости и запустит сервер и клиент в отдельных окнах.

Перейдите на http://localhost:5173/

#### Вариант Б: Ручной запуск

#### Бэкенд
```bash
cd server
npm install
npm start
```
Сервер запустится на [http://localhost:5000](http://localhost:5000).

#### Фронтенд
Откройте новое окно терминала:
```bash
cd client
npm install
npm run dev
```
Приложение будет доступно по адресу [http://localhost:5173](http://localhost:5173).

## Структура проекта
Проект разделен на логические модули для удобства масштабирования и тестирования:
- **/client**: React приложение.
  - `src/hooks`: Кастомные хуки для логики чата и речи.
  - `src/components`: Переиспользуемые UI компоненты.
- **/server**: Express API.
  - `controllers/`: Логика обработки запросов.
  - `routes/`: Определение эндпоинтов.
  - `middlewares/`: Глобальная обработка ошибок и безопасность.
